# 关节

## CreateDistanceJoint

服务端

method in mod.server.component.physxCompServer.PhysxComponentServer

- 描述

  创建距离关节，限制两个锚点之间的距离范围，可配弹簧

- 参数

| 参数名 | 数据类型 | 说明 |
| --- | --- | --- |
| entityId0 | str | 第一个实体id，传空字符串""表示锚定到世界 |
| entityId1 | str | 第二个实体id |
| anchor0 | `tuple(float,float,float)` | 第一个Joint frame原点的世界坐标 |
| anchor1 | `tuple(float,float,float)` | 第二个Joint frame原点的世界坐标，可与anchor0不同 |

- 返回值

| 数据类型 | 说明 |
| --- | --- |
| int | 关节id；失败返回None |

- 示例

```python
import mod.server.extraServerApi as serverApi
levelComp = serverApi.GetEngineCompFactory().CreatePhysx(serverApi.GetLevelId())
jointId = levelComp.CreateDistanceJoint(entityId0, entityId1, (0, 80, 0), (0, 77, 0))
levelComp.SetDistanceJointParams(jointId, 2.0, 4.0, 200.0, 30.0, 14)

```

## CreatePrismaticJoint

服务端

method in mod.server.component.physxCompServer.PhysxComponentServer

- 描述

  创建滑动关节；两个刚体仅能沿指定轴相对平移，旋转被锁定，可加行程限制

- 参数

| 参数名 | 数据类型 | 说明 |
| --- | --- | --- |
| entityId0 | str | 第一个实体id，传空字符串""表示锚定到世界 |
| entityId1 | str | 第二个实体id |
| anchor0 | `tuple(float,float,float)` | 第一个Joint frame原点的世界坐标，通常与anchor1相同 |
| anchor1 | `tuple(float,float,float)` | 第二个Joint frame原点的世界坐标，通常与anchor0相同 |
| axis | `tuple(float,float,float)` | 世界坐标系滑动轴方向，无需预归一化，对应Joint frame的+X轴；零向量退化为世界+X轴 |

- 返回值

| 数据类型 | 说明 |
| --- | --- |
| int | 关节id；失败返回None |

- 示例

```python
import mod.server.extraServerApi as serverApi
levelComp = serverApi.GetEngineCompFactory().CreatePhysx(serverApi.GetLevelId())
jointId = levelComp.CreatePrismaticJoint(entityId0, entityId1, (0, 80, 0), (0, 80, 0), (1, 0, 0))

```

## SetJointBreakForce

服务端

method in mod.server.component.physxCompServer.PhysxComponentServer

- 描述

  设置关节可承受的约束力/约束扭矩阈值；PhysX求解出的实际约束载荷超过任一阈值时自动断裂。冲量(eIMPULSE，单位N·s)不能直接与力阈值(N)比较

- 参数

| 参数名 | 数据类型 | 说明 |
| --- | --- | --- |
| jointId | int | 关节id |
| force | float | 最大允许约束力(N)；必须为非负有限数，-1 表示不可断裂 |
| torque | float | 最大允许约束扭矩(N·m)；必须为非负有限数，-1 表示不可断裂 |

- 返回值

| 数据类型 | 说明 |
| --- | --- |
| bool | 是否成功 |

- 示例

```python
import mod.server.extraServerApi as serverApi
levelComp = serverApi.GetEngineCompFactory().CreatePhysx(serverApi.GetLevelId())
levelComp.SetJointBreakForce(jointId, 500.0, 100.0)

```
