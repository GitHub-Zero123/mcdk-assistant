# 刚体

## AddForce

服务端

method in mod.server.component.physxCompServer.PhysxComponentServer

- 描述

  对自定义刚体的质心施加全局坐标力；数值单位由mode决定，对运动学刚体无效

- 参数

| 参数名 | 数据类型 | 说明 |
| --- | --- | --- |
| dir | `tuple(float,float,float)` | 全局坐标输入向量：eFORCE为力(N)，eIMPULSE为冲量(N·s)，eVELOCITY_CHANGE为速度变化(m/s)，eACCELERATION为加速度(m/s²) |
| mode | int | PxForceMode枚举：eFORCE=0、eIMPULSE=1、eVELOCITY_CHANGE=2、eACCELERATION=3 |

- 返回值

| 数据类型 | 说明 |
| --- | --- |
| bool | 是否成功 |

- 示例

```python
import mod.server.extraServerApi as serverApi
from common.minecraftEnum import PxForceMode
comp = serverApi.GetEngineCompFactory().CreatePhysx(entityId)
# 添加一个向上的速度
comp.AddForce((0,1,0), PxForceMode.eVELOCITY_CHANGE)

```

import mod.server.extraServerApi as serverApi
