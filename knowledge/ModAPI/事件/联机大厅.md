# 联机大厅

## RoomHostChangedServerEvent

服务端

- 描述

  联机大厅房主实际改变后触发。非联机大厅不触发；房主uid未变化不触发。

- 参数

| 参数名 | 数据类型 | 说明 |
| --- | --- | --- |
| newUid | int | 新房主uid |
| newEntityId | str/None | 新房主entityId，不在线则为None |
| oldUid | int | 原房主uid；首次设置房主时为0 |
| oldEntityId | str/None | 原房主entityId，不在线或首次设置时为None |

- 返回值

  无

- 备注

  - 仅联机大厅触发。
  - newEntityId/oldEntityId 依赖对应玩家是否在线，离线时为None；uid字段则始终有效。

## lobbyGoodBuySucServerEvent

服务端

- 描述

  玩家登录联机大厅服务器，或者联机大厅游戏内购买商品时触发。如果是玩家登录，触发时玩家客户端已经触发了UiInitFinished事件

- 参数

| 参数名 | 数据类型 | 说明 |
| --- | --- | --- |
| eid | str | 购买商品的玩家实体id |
| buyItem | bool | 玩家登录时为False，玩家购买了商品时为True |

- 返回值

  无
