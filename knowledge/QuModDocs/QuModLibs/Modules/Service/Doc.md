# Service 服务

Service 是可选的管理层抽象，用来承载长期生命周期、统一回收、内部定时器或本地服务事件等管理需求。

::: warning 默认从模块级组织开始
大多数业务直接依赖 Python 模块即可：模块天然单例，配合静态 `@Listen("EventName")`、`@AllowCall`、普通函数和模块级状态，通常已经足够清晰。即便需要 class，也往往只是普通业务类、数据类或小型管理类，不一定需要上升到服务类。
:::

把 `BaseService` 当作管理层工具，而不是常规业务入口。只有当您已经能明确说出“这组逻辑需要被统一启动、停止、回收，或者需要服务内事件广播”时，再引入服务类通常更稳。
