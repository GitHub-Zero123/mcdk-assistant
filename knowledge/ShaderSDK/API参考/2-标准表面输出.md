# StandardSurfaceOutput

StandardSurfaceOutput 是 CSS 入口函数的读写输出结构。各字段的有效渲染环境不同：花式渲染器只使用 Albedo 和 Alpha，灵动视效还使用 PBR 表面字段。

## 字段

| 字段 | 数据类型 | 默认值 | 说明 | 生效环境 |
| --- | --- | --- | --- | --- |
| Albedo | vec3 | (1, 1, 1) | 基础（漫反射）表面颜色 | 全部 |
| Alpha | float | 1.0 | 用于混合或 Alpha 测试的不透明度 | 全部 |
| Metallic | float | 0.0 | PBR 金属度；0 为电介质，1 为金属 | 仅灵动视效 |
| Roughness | float | 1.0 | PBR 粗糙度；0 为光滑，1 为粗糙 | 仅灵动视效 |
| Emissive | float | 0.0 | 加到表面颜色上的自发光量；不向邻近表面提供光照 | 仅灵动视效 |
| Subsurface | float | 0.0 | 半透明材质的次表面散射量 | 仅灵动视效 |
| ViewSpaceNormal | vec3 | (0, 1, 0) | 延迟光照使用的视空间逐片元法线 | 仅灵动视效 |

## 环境差异

| 渲染环境 | 消费的字段 |
| --- | --- |
| 花式渲染器 | Albedo、Alpha |
| 灵动视效 | 全部字段 |

Metallic、Roughness、Emissive、Subsurface 和 ViewSpaceNormal 只输入灵动视效的延迟光照模型；花式渲染器不使用这些字段。

## 读写规则

- surfaceOutput 使用 inout 传递，入口函数可读取字段当前值并写回结果。
- 表中的默认值是 r21u12 规格定义的字段默认值。
- PBR 字段进入灵动视效的延迟光照模型。目标同时对应 Prepass 与 ForwardPBR 材质时，两条材质路径的覆盖要求见[根类型与材质映射](https://mc.163.com/dev/mcmanual/mc-dev/mcdocs/4-ShaderSDK/API%E5%8F%82%E8%80%83/6-%E6%A0%B9%E7%B1%BB%E5%9E%8B%E4%B8%8E%E6%9D%90%E8%B4%A8%E6%98%A0%E5%B0%84.html)。
