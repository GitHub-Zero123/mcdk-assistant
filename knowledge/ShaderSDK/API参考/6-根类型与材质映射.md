# 根类型与材质映射

在 r21u12 中，Custom Surface Shader 必须附着到一个根类型（Root Type）：

```
CustomSurfaceShader "MyShader" : "RootType"

```

根类型表示玩法层面的渲染目标。引擎根据当前渲染环境，将根类型映射到花式渲染器或灵动视效使用的具体材质。

## 有效根类型

| 根类型 | 对应内容 | 是否映射到 Prepass 材质 |
| --- | --- | --- |
| Terrain | 地形、世界区块与水面 | 是 |
| Actor | 玩家、生物和一般实体 | 是 |
| Particle | 粒子广告牌 | 是 |
| Weather | 雨、雪、孢子和灰烬 | 否 |
| Sky | 主世界与下界天空 | 否，共用材质 |
| EndSky | 末地星空 | 否 |
| Clouds | 云层 | 否 |
| Stars | 夜空星场 | 否 |
| SunMoon | 太阳与月亮 | 否 |
| EndPortal | 末地传送门表面 | 否 |
| ItemInHand | 第一人称手持物品 | 是 |

## Prepass 与 ForwardPBR

在灵动视效路径中，\*Prepass 材质将表面属性写入延迟 G-buffer，\*ForwardPBR 材质执行受光着色。

在 r21u12 的根类型覆盖路径中，引擎会将 CSS 应用到该根类型对应的背后材质。对于同时映射到 \*Prepass 和 \*ForwardPBR 的根类型，当前路径会覆盖两者。

r21u12 规格的前瞻说明指出，后续版本将改为支持材质类型目标，根类型覆盖不会继续作为受支持的附着方式。目标版本开始使用材质类型后，如果一个玩法目标同时使用 \*Prepass 和 \*ForwardPBR，开发者需要分别覆盖两个材质，以避免两条路径使用不一致的表面数据。

## Terrain

允许的 Intrinsic Family：TerrainInfo、GeoType。

| 花式渲染器 | 灵动视效 ForwardPBR | 灵动视效 Prepass | 说明 |
| --- | --- | --- | --- |
| RenderChunk | RenderChunkForwardPBR | RenderChunkPrepass | 地形与世界区块，包括不透明、Alpha、混合、季节和远景渲染 |
| — | — | WaterPrepass | 水面对延迟几何 Prepass 的贡献 |

## Actor

| 花式渲染器 | 灵动视效 ForwardPBR | 灵动视效 Prepass | 说明 |
| --- | --- | --- | --- |
| Actor | ActorForwardPBR | ActorPrepass | 玩家、生物及一般实体几何 |
| ActorBanner | ActorBannerForwardPBR | ActorBannerPrepass | 分层图案合成的旗帜实体 |
| ActorGlint | ActorGlintForwardPBR | ActorGlintPrepass | 实体上的附魔或充能光效 |
| ActorMultiTexture | ActorMultiTextureForwardPBR | ActorMultiTexturePrepass | 混合多张纹理的实体 |
| ActorPattern | ActorPatternForwardPBR | ActorPatternPrepass | 图案驱动的实体 |
| ActorPatternGlint | ActorPatternGlintForwardPBR | ActorPatternGlintPrepass | 带附魔光效的图案实体 |
| ActorTint | ActorTintForwardPBR | ActorTintPrepass | 带额外染色通道的实体 |

## Particle

## 迁移说明

本页映射只适用于 r21u12 的根类型覆盖路径。开发者升级项目版本时，应先确认目标版本是否仍支持根类型覆盖；如果目标版本已采用材质类型目标，应按照该版本公布的有效材质类型与映射修改 CSS，不应继续使用本页映射作为实现依据。
