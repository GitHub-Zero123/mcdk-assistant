# 热更新缓存协议

## 概述

`AuroraCache` 是一套伪造的插件侧缓存协议，用来演示自定义资料库搜索。它把配置、索引和脚本元数据拆成三个 namespace：`config`、`index`、`script_meta`。

缓存项包含 `key`、`value`、`etag`、`created_at`、`expires_at`。当插件触发热更新时，只要 `etag` 未变化，就不会重复构建索引。

## 懒构建

目录型资料库推荐使用懒构建。插件加载时只登记数据源，不立刻扫描文件。第一次调用搜索工具时，索引才会真正扫描 Markdown 文档并构建倒排表。

这样可以降低启动耗时，也方便测试插件安装后是否能被快速发现。

## 失效与重建

当文档目录发生变化时，插件可以调用 `invalidate()` 标记缓存为脏数据。下一次搜索会重新构建，或者也可以主动调用 `rebuild()` 立即刷新。

测试关键词：缓存、热更新、etag、懒构建、invalidate、rebuild。
